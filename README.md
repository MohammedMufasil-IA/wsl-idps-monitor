# WSL Intrusion Detection and Prevention System (IDPS)

A real-time log monitoring, automated notification, and network-level mitigation system built in WSL (Ubuntu) using Bash, Python, and iptables.

## Features
- Real-time log parsing (`traffic_logs.txt`)
- Automated `iptables` firewall blocking (`DROP` rules)
- Windows native PowerShell desktop alerts
- Interactive HTML security visualization dashboard
